EXPLORE YOUR KNOWLEDGE

Find meaning. Follow connections.

Find saved nodes by name, meaning, or a read-only Cypher query, then explore their relationships.

Vector search embeds node names with the local BGE model. It downloads lazily on first use and caches the model for later searches.

Cypher examples and supported syntax

Use Entity for nodes and Link for relationships. The selected graph is scoped automatically. Filter only by node name, id/uuid, or relationship name. Descriptions are included in results.

MATCH (n:Entity) WHERE lower(n.name) CONTAINS 'alice'
RETURN n.id, n.name, n.description
MATCH (n:Entity {id: 'paste-node-uuid-here'}) RETURN n
MATCH (a:Entity)-[r:Link]->(b:Entity)
WHERE r.name = 'WORKS_AT'
RETURN a.name AS source, r.name AS relationship, b.name AS target

Supported: one MATCH, fixed-length paths, WHERE, RETURN, DISTINCT, ORDER BY, and LIMIT. Mutations, procedures, aggregates, comments, and subqueries are not supported. Queries have a 5-second execution limit.
